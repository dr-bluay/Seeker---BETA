# Seeker - BETA

Seeker

Seeker is an HTML-based OSINT tool designed to help users identify publicly available email information associated with GitHub users and profiles.

Features

- Search GitHub users by username.
- Extract publicly available email information when it is exposed by the user.
- Simple and lightweight HTML interface.
- Intended for research, OSINT, and educational purposes.

Ethical Use Only

Seeker is intended strictly for ethical and lawful purposes. Only use information that is publicly available and respect GitHub's terms of service, user privacy, and applicable laws. Do not use Seeker to harass, spam, impersonate, or target individuals.

The developer is not responsible for misuse of the tool.
